# Калькулятор метаболитов эстрогенов

Статический сайт для врача: ввод или загрузка бланка анализа метаболитов эстрогенов (суточная моча, панель 6 метаболитов, DUTCH), расчёт соотношений 2-OH / 4-OH / 16α-OH, метилирования (COMT), эстрогенного коэффициента, рекомендации и проект заключения. Учитываются полиморфизмы генов CYP1A1, CYP1A2, CYP1B1, CYP3A4, CYP19A1, CYP17A1, COMT, MTHFR, MTR, MTRR, GSTM1, GSTT1, GSTP1, NQO1, SULT1A1, UGT1A1, ESR1, PGR; генетические бланки (MyGenetics, «Аллель» и др.) загружаются из PDF.

PDF и фото бланков обрабатываются полностью в браузере пользователя (pdf.js, Tesseract.js). Файлы никуда не отправляются.

## Структура

```
index.html            страница калькулятора
importer.js           чтение PDF, распознавание сканов и фото, разбор показателей и генотипов
schema.js             вкладка «Схема»: стероидогенез и метаболизм эстрогенов пациента, выгрузка PNG и PDF
saliva.js             вкладка «Слюна»: стероидный профиль в слюне (Гемотест 2.80, 2.79, 2.75 и аналоги), импорт бланка, соотношения, выводы
lib/jspdf.umd.min.js  jsPDF 2.5.1 (MIT), сборка PDF
genes.js              каталог полиморфизмов ферментов синтеза, биотрансформации и рецепции эстрогенов
lib/pdf.min.js        pdf.js 3.11.174 (Apache-2.0)
lib/pdf.worker.min.js
lib/tesseract/        Tesseract.js 5.1.1 (Apache-2.0), ядро и языковые модели rus/eng
```

## Публикация через GitHub Pages

1. Создайте репозиторий на github.com (кнопка New), например `estrogen-calculator`.
2. Загрузите в корень репозитория все файлы из этой папки, сохранив структуру `lib/`.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/estrogen-calculator/`.

Локальный просмотр: `python3 -m http.server` в этой папке, затем http://localhost:8000.
